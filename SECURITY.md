# Security Policy

## Purpose

This policy defines how security issues are reported and handled across the Vane Enterprise LLC GitHub organization.

## Reporting a Vulnerability

Please do not disclose vulnerabilities publicly. Instead, follow the private disclosure process for the relevant repository or contact the repository owners directly.

Preferred channels:

- GitHub Security Advisory if enabled for the repository
- repository maintainer contact
- organization security contact

## Reporting Template

Include:

- description of the issue
- affected component, repo, or version
- reproduction steps
- impact assessment
- suggested mitigation or fix

## Response Expectations

We aim to acknowledge valid reports promptly and work toward a coordinated fix in a responsible, professional manner.

## Responsible Disclosure

We appreciate careful, responsible disclosure and will handle reports with seriousness and discretion.
